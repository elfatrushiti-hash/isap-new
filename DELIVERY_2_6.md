# ISAP Delivery 2.6 - Presentation Mode

## Included
- Start Presentation Mode directly from Administration > Presentations.
- Full-screen capable presentation canvas.
- Arrow, PageUp/PageDown and Space keyboard navigation.
- Manual slide browser to jump freely to any slide.
- Speaker Notes overlay.
- AI Guidance side panel using Slide Intelligence metadata.
- Meeting timer with start, pause and reset.
- Persistent last slide, elapsed time and panel state per presentation.
- Responsive desktop and mobile behavior.

## Keyboard shortcuts
- Arrow Left / PageUp: previous slide
- Arrow Right / PageDown / Space: next slide
- N: toggle speaker notes
- I: toggle AI Guidance
- L: toggle slide list
- Escape: exit fullscreen / presentation mode
