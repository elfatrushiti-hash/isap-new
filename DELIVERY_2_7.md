# Delivery 2.7 - ISAP Rule Intelligence Core

This delivery turns the rule-based intelligence concept into an administrable product capability.

- New Administration > Intelligence Core
- Persistent dictionary/taxonomy rules in localStorage
- Editable terms, types and weights
- Explainability laboratory with deterministic confidence scoring
- Rule provider service with explicit `externalTransmission: false`
- External AI provider remains structurally reserved and visibly locked
- No network/API integration is introduced by this delivery

Security posture: RULE mode only. This delivery does not upload customer, meeting, document or intelligence data to an external AI provider.
