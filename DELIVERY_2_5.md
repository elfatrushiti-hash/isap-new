# Delivery 2.5 - AI Presentation Builder

New in this delivery:
- AI Presentation Builder in Administration > Presentations
- Meeting context input (company, industry, audience, products, objectives)
- Ranked slide plan based on the existing 2.4 Recommendation Engine
- Manual inclusion/exclusion of suggested slides
- Manual slide reordering
- Editable title and description before creation
- Creates a normal editable draft presentation in the existing Presentation Library
- Generated slides retain source presentation references for traceability
- Generated presentation metadata stores the meeting context

This is intentionally a rule-based/local first implementation. A later AI provider can replace or augment the ranking and content-generation layer without changing the UI workflow.
