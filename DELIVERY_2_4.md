# Delivery 2.4 - AI Presentation Recommendation Engine

## Included
- Meeting-context driven recommendation dialog in the Presentation Library
- Ranking for presentations, individual slides and related assets
- Weighted scoring for product, industry, topic, audience, recency, quality and favorites
- Explainable match reasons and confidence percentages
- Direct opening of recommended presentations
- Persistent recommendation run history in localStorage
- API-ready recommendation service without an external LLM dependency

## Usage
Open **Administration > Presentations** and select **AI recommendations**. Add the available customer and meeting signals, select relevant products and generate the ranked content selection.
